# ワイヤーフレーム

## 概要

このファイルは、自家焙煎コーヒー豆ECの初回リリースにおける主要画面のワイヤーフレームを整理したものです。  
商品一覧、商品詳細、カート画面を対象に、お客さんが商品を選び、カートに入れ、決済へ進むまでの画面構成を確認します。  
データ項目は主に `products` とカート内の商品情報を前提にしています。

## 商品一覧画面

### ASCIIワイヤー

```text
+--------------------------------------------------------------------------------+
| MAME COFFEE                                      [カート]  [ログイン状態]       |
+--------------------------------------------------------------------------------+
|                                                                                |
| 今月のコーヒー豆                                                              |
| 季節限定の自家焙煎豆を、今月は3種類だけ販売しています。                       |
|                                                                                |
| +----------------------+  +----------------------+  +----------------------+   |
| |      商品画像        |  |      商品画像        |  |      商品画像        |   |
| |                      |  |                      |  |                      |   |
| | エチオピア 浅煎り    |  | グアテマラ 中煎り    |  | ブラジル 深煎り      |   |
| | ¥1,500               |  | ¥1,400               |  | ¥1,300               |   |
| |                      |  |                      |  |                      |   |
| | クリックで詳細へ     |  | クリックで詳細へ     |  | クリックで詳細へ     |   |
| +----------------------+  +----------------------+  +----------------------+   |
|                                                                                |
+--------------------------------------------------------------------------------+
| フッター: 店舗情報 / 配送・返品について / お問い合わせ                         |
+--------------------------------------------------------------------------------+
```

### 要素一覧

| 要素 | 表示内容 | 役割 |
|---|---|---|
| ヘッダー | サイトロゴ、カート、ログイン状態 | 全画面共通のナビゲーション |
| 見出し | 今月のコーヒー豆 | 月替わりの商品一覧であることを伝える |
| 説明文 | 季節限定・少量販売の案内 | 店舗の特徴を伝える |
| 商品カード | 画像、商品名、価格 | `products` の商品情報を一覧表示する |
| 商品名 | `products.name` | 商品を識別する |
| 価格 | `products.price_jpy` | 販売価格を表示する |
| カードクリック | 商品詳細へ遷移 | 商品詳細画面を開く |

## 商品詳細画面

### ASCIIワイヤー

```text
+--------------------------------------------------------------------------------+
| MAME COFFEE                                      [カート]  [ログイン状態]       |
+--------------------------------------------------------------------------------+
|                                                                                |
| [商品一覧へ戻る]                                                               |
|                                                                                |
| +------------------------------+  エチオピア 浅煎り                            |
| |                              |  ¥1,500 / 100g                                |
| |          商品画像            |                                                |
| |                              |  産地: エチオピア                             |
| |                              |  焙煎度: 浅煎り                               |
| +------------------------------+  味わい: すっきり、華やか、果実感             |
|                                                                                |
| 在庫: 残りわずか                                                               |
| 販売期間: 2026/07/01 - 2026/07/31                                               |
|                                                                                |
| 店主コメント                                                                   |
| 今月の朝におすすめしたい、軽やかで香りのよい豆です。                           |
|                                                                                |
| 数量: [-] 1 [+]                         [カートに追加]                         |
|                                                                                |
+--------------------------------------------------------------------------------+
| フッター: 店舗情報 / 配送・返品について / お問い合わせ                         |
+--------------------------------------------------------------------------------+
```

### 要素一覧

| 要素 | 表示内容 | 役割 |
|---|---|---|
| 戻るリンク | 商品一覧へ戻る | トップの商品一覧に戻る |
| 商品画像 | 商品の写真 | 商品の雰囲気を伝える |
| 商品名 | `products.name` | 商品を識別する |
| 価格 | `products.price_jpy` | 販売価格を表示する |
| 内容量 | `products.weight_grams` | 購入単位を表示する |
| 産地 | `products.origin` | 豆の基本情報を表示する |
| 焙煎度 | `products.roast_level` | 味の傾向を伝える |
| 味わい | `products.flavor_notes` | 専門知識がなくても選びやすくする |
| 在庫 | `products.stock_quantity` | 購入できるか判断できるようにする |
| 販売期間 | `products.sales_start_date` / `products.sales_end_date` | 限定感と販売期限を伝える |
| 店主コメント | `products.shop_comment` | 小さなお店らしいこだわりを伝える |
| 数量変更 | `[-]` / `[+]` | カートに入れる数量を調整する |
| カートに追加 | ボタン | 選択した商品と数量をカートへ追加する |

## カート画面

### ASCIIワイヤー

```text
+--------------------------------------------------------------------------------+
| MAME COFFEE                                      [カート]  [ログイン状態]       |
+--------------------------------------------------------------------------------+
|                                                                                |
| カートに入っている商品                                                        |
|                                                                                |
| +----------------------------------------------------------------------------+ |
| | [商品画像]  エチオピア 浅煎り                                               | |
| |             単価: ¥1,500                                                    | |
| |             数量: [-] 1 [+]                              [削除]             | |
| +----------------------------------------------------------------------------+ |
|                                                                                |
| +----------------------------------------------------------------------------+ |
| | [商品画像]  グアテマラ 中煎り                                               | |
| |             単価: ¥1,400                                                    | |
| |             数量: [-] 2 [+]                              [削除]             | |
| +----------------------------------------------------------------------------+ |
|                                                                                |
| ------------------------------------------------------------------------------ |
|                                                       合計金額: ¥4,300          |
|                                                                                |
|                                                       [決済に進む]             |
|                                                                                |
+--------------------------------------------------------------------------------+
| フッター: 店舗情報 / 配送・返品について / お問い合わせ                         |
+--------------------------------------------------------------------------------+
```

### 要素一覧

| 要素 | 表示内容 | 役割 |
|---|---|---|
| 見出し | カートに入っている商品 | カート内容の確認エリアを示す |
| 商品画像 | カート内商品の画像 | 商品を視覚的に確認する |
| 商品名 | `products.name` | カート内の商品名を表示する |
| 単価 | `products.price_jpy` | 現在の商品の単価を表示する |
| 数量変更 | `[-]` / `[+]` | 購入数量を変更する |
| 削除ボタン | 削除 | カートから商品を取り除く |
| 合計金額 | 単価 × 数量の合計 | 決済前に支払予定金額を確認する |
| 決済に進む | ボタン | 決済画面へ進む。未ログインの場合はログイン画面を挟む |

## 共通ヘッダー・フッターの仕様

### 共通ヘッダー

| 要素 | 表示内容 | 役割 |
|---|---|---|
| サイトロゴ | MAME COFFEE | クリックすると商品一覧画面へ戻る |
| カート | カートアイコンまたはテキスト | カート画面へ遷移する |
| ログイン状態 | ログイン / ログイン中 | 未ログイン時はログイン導線、ログイン済みなら状態表示にする |

### 共通フッター

| 要素 | 表示内容 | 役割 |
|---|---|---|
| 店舗情報 | 店舗名や簡単な紹介 | 小さなお店の信頼感を伝える |
| 配送・返品について | 配送日数、返品条件への案内 | 購入前の不安を減らす |
| お問い合わせ | 問い合わせ導線 | 購入前後の質問を受け付ける |

### 補足

- 商品一覧、商品詳細、カート画面では同じヘッダーを使い、画面間の移動を分かりやすくします。
- ログイン状態は Supabase Auth の認証状態をもとに表示を切り替える想定です。
- 初回リリースでは、お気に入り、レビュー、再入荷通知、ギフト設定、詳細なマイページは画面に含めません。
